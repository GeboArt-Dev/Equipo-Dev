# Reiniciar el contexto del equipo

Este adaptador no tiene panel persistente ni estado propio que vaciar. No borres documentos, historial, configuraciones o archivos del proyecto.
Indica que el usuario puede abrir una sesión nueva e invocar feature con el nombre de la siguiente funcionalidad; los documentos anteriores se conservan para retomar trabajo.
